# FLUS

Norwegian job marketplace connecting employers with local workers.

## Stack

Next.js · TypeScript · Supabase (PostgreSQL) · Vipps OAuth · Tailwind CSS · Playwright

## Getting started

```bash
npm install
cp .env.example .env.local
# Run migrations in Supabase SQL Editor (supabase/migrations/ in order)
npm run dev
```
